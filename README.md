# Lorena's Portfolio

A personal portfolio website designed to showcase my projects, technical skills, education, and learning journey as a junior developer.

The portfolio serves as a central hub for the work I've created throughout my studies and self-learning, including web applications, small JavaScript games, Android applications, and my Bachelor's thesis.

## Live Demo

https://t4bbyp.github.io/lorena/

## Features

- Custom retro-inspired portfolio interface and animated UI elements
- Interactive game-like project map with dynamically generated project nodes
- SVG-based connections between projects
- Data-driven architecture powered by JSON files
- Dynamically generated project pages and galleries
- Image carousel system for project screenshots
- Skills, certificates, and project information loaded through JavaScript
- External links to GitHub, LinkedIn, and CodePen
- GitHub Pages deployment

## Tech Stack

* HTML5
* CSS3
* Vanilla JavaScript
* JSON
* GitHub Pages
  
## Why I Built This

As an aspiring software developer without professional industry experience yet, I wanted a dedicated space where I could gather the projects I've created while learning and practicing programming.

The goal was to build a portfolio that is both informative and visually memorable while giving recruiters and employers an easy way to explore my work, skills, and technical background.

## What I Learned

Through this project I practiced:

* DOM manipulation with Vanilla JavaScript
* Working with external JSON data
* Dynamic content rendering
* UI/UX design principles
* Organizing larger frontend projects
* Git and GitHub Pages deployment
* Creating reusable interface components without frameworks
